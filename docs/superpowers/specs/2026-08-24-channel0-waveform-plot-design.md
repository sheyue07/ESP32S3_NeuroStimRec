# 通道 0 波形绘图脚本设计

日期：2026-08-24

## 目标

直接修改 `data0822/2/huizhiboxing.m`，读取同目录下的标准 MAT 数据和 SD MAT 数据，仅绘制通道 0 的原始采样波形。

## 数据与绘图

- 标准文件：`202608221612.mat`，变量 `data_all`。
- SD 文件：`run_1_segment_1.mat`，变量 `data_SD`。
- 两个矩阵均为 `128 × 帧数 uint16`；通道 0 对应 MATLAB 第 1 行。
- 创建两个独立 Figure，不叠加、不执行时间对齐。
- Figure 1 标题为“标准数据”；Figure 2 标题为“SD数据”。
- 横轴为采样点序号，纵轴为 ADC 原始采样值。
- 默认绘制各自完整波形。

## 路径和错误处理

- 使用 `mfilename('fullpath')` 定位脚本目录，不依赖 MATLAB 当前工作目录。
- 加载后检查 `data_all` 和 `data_SD` 是否存在，并检查矩阵至少有一行；条件不满足时给出明确错误。
